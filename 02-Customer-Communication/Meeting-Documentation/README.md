Meeting Documentation – Legacy-to-Flows Migration
Overview

This document demonstrates the use of Minutes of Meeting (MoM) to capture discussions, decisions, open questions, and action items during a legacy-to-new-platform migration project.

The project involved migrating from a legacy/classic solution to a new flows-based solution. During the migration, an issue was identified where customer-facing data was not rendering correctly after communication data was sent through the new solution.
