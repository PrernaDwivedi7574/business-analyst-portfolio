# Project Description

This project focuses on sending timely payment reminders to customers based on customer and payment data.

Business rules and communication strategies are defined based on factors such as upcoming payment due dates, overdue payments, and whether the customer has already made the payment.

Based on these rules, the system determines the appropriate communication outcome and sends reminders through Email, SMS, or Voice/IVR.
